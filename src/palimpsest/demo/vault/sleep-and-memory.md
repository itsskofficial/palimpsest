# Sleep and memory

Memory consolidation happens largely during sleep. What was learned during the day is
replayed and moved from short-term storage into more durable form, which is why a
night of sleep after studying is worth more than the equivalent hours awake.

## Slow-wave sleep

Declarative memory — facts, events, things you could state out loud — is consolidated
mainly during slow-wave sleep, which is concentrated in the first half of the night.

## The practical version

Cutting sleep short after a hard learning day costs more than it seems to: the hours
lost are disproportionately the ones doing the consolidating.
